# 03 · 接口设计与接口文档

> 来源：真实 Controller 注解扫描 + 前端 `api/index.js` 调用扫描 + 实测响应。禁止虚构。
> Base URL：`http://localhost:8080/api`（前端经 Vite/nginx 代理同源 `/api`）
> 统一响应：`{code: 200成功|400参数|401未认证|403无权限|500异常, message, data}`；HTTP 状态恒 200（错误以 code 表达）
> 身份头：管理员 `X-Admin-Id`（admins.admin_id）；公众/网格员 `X-User-Id`（users.id）；并携带 `Authorization: Bearer <token>`

## 2. 核心接口请求/响应示例（实测）

### 2.1 公众登录
```json
POST /api/auth/login-public  {"username":"zhang_san","password":"123456"}
→ 200 {"code":200,"message":"登录成功","data":{"token":"...32位","userId":590,"username":"zhang_san","nickname":"张三"}}
错误：400 用户名和密码不能为空 / 401 用户名或密码错误 / 403 账号已被禁用
```

### 2.2 创建监督事件
```json
POST /api/supervision  header: X-User-Id: 590
body: {"eventType":"POLLUTION","level":"ALARM","title":"和平区空气异味投诉","description":"...","location":"和平区XX路","deviceId":486,"regionId":19,"attachments":[{"fileName":"a.jpg","fileSize":2048,"contentType":"image/jpeg"}]}
→ 200 {"code":200,"message":"提交成功","data":{"id":"360","eventNo":"ENV-20260902-001","status":"PENDING_REVIEW",...}}
错误：400 事件类型不能为空/标题不能为空/非法事件类型/关联设备不存在；401 未登录
说明：status 由后端强制 PENDING_REVIEW，body 传 status 无效（防注入实测）。
```

### 2.3 管理员审核/派单
```json
PUT /api/supervision/{id}/approve  header: X-Admin-Id: 1  body: {"remark":"情况属实"}
→ 200 data.status = APPROVED；仅 PENDING_REVIEW 可审（其余 400）
PUT /api/supervision/{id}/assign  body: {"gridId":131,"assigneeId":591,"priority":"HIGH","deadline":"2026-09-03 18:00:00"}
→ 200 data.status = ASSIGNED（同时创建 inspection_task 并写日志）；仅 APPROVED 可派
```

### 2.4 网格员提交检测
```json
PUT /api/tasks/mine/{id}/submit  header: X-User-Id: 591
body: {"pm25":88.5,"pm10":135.0,"so2":12.0,"no2":55.0,"co":0.9,"o3":95.0,"content":"...","images":["a.jpg"],"lat":31.2305,"lng":121.4738}
→ 200 data.status = INSPECTED；AQI=117 由后端按 HJ633-2012 计算入 inspection_record
错误：400 至少一项检测值/当前状态不允许；403 非本人任务
```

### 2.5 管理员核实/关闭/查看记录
```json
PUT /api/tasks/{id}/verify → data.status=VERIFIED（仅 INSPECTED）
PUT /api/tasks/{id}/close → data.status=CLOSED（仅 VERIFIED；事件同步 CLOSED + 通知提交人）
GET /api/tasks/{id}/records → data=[{taskId,pm25..o3,aqiValue,images[],lat,lng,recorderName,createTime}]
```

### 2.6 监督详情（时间线）
```json
GET /api/supervision/{id}（本人或管理员）
→ data.event.status=CLOSED, data.taskId="189", data.taskNo="TK-20260902-001", data.attachments=[...], data.statusLogs=[{fromStatus,toStatus,operatorName,remark,createTime}×8]
```

### 2.7 统计
```json
GET /api/stats/overview → data: {totalDevices,onlineDevices,todayReports,unhandledAlerts,todayEvents,pendingReview,processing,closedEvents,eventHandleRate,totalEvents}
GET /api/stats/supervision → data: {regionDistribution[],typeDistribution[],taskStats{totalTasks,closedTasks,completionRate},gridTasks[],highRiskEvents[],eventTrend[]}
```

## 3. 错误码约定

| code | 含义 | 场景 |
|---|---|---|
| 200 | 成功 | |
| 400 | 参数/状态非法 | 不存在 ID、非法状态转换、重复操作、参数类型错误、缺字段 |
| 401 | 未认证 | 无身份头、登录失败、账号禁用 |
| 403 | 无权限 | 越权（他人事件/任务）、伪造管理员 |
| 500 | 系统异常 | 兜底（当前会返回 e.getMessage()，见《07》BUG-004） |

## 4. 前端调用与后端一致性

四端 84 个前端封装全部命中后端真实端点（另有 3 个后端死接口未被调用）（动态验证：逐接口比对一致）；字段 camelCase 统一；分页 {total,pages,records}；Long id 字符串化。详见《API-Contract-Matrix》。
