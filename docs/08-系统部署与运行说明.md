## 3. 数据库初始化

库 `nep`（utf8mb4），连接：localhost:3306 root/124102（本机 application.properties，不入库；部署请用环境变量/独立配置）。

```bash
mysql -uroot -p124102 < nepsystem/src/main/resources/db/init.sql
mysql -uroot -p124102 < nepsystem/src/main/resources/db/migration_v2.sql
mysql -uroot -p124102 < nepsystem/src/main/resources/db/migration_v3.sql
mysql -uroot -p124102 < nepsystem/src/main/resources/db/migration_v4.sql
mysql -uroot -p124102 < nepsystem/src/main/resources/db/migration_v5.sql
mysql -uroot -p124102 < nepsystem/src/main/resources/db/migration_v6.sql
mysql -uroot -p124102 < nepsystem/src/main/resources/db/demo_business_chain.sql   # 演示基础数据(可选)
```

注意：migration_v2~v6 使用 ALTER/CREATE（非全部幂等），仅初始化一次；已初始化的库不要重复执行。

## 4. 启动顺序

1. MySQL（服务已启动）；2. 后端；3. 四个前端。

### 后端
```bash
cd C:\Users\LZ\Desktop\drenep\nepsystem
# 方式A 打 jar 运行（推荐）
mvn clean package -DskipTests
java -jar target/nepsystem-0.2.0.jar            # 模拟器开（默认 simulator.enabled=true，5s/轮）
java -jar target/nepsystem-0.2.0.jar --simulator.enabled=false   # 关闭模拟器（纯业务演示/验证）
# 方式B 源码运行
mvn spring-boot:run
# 方式C IDE：运行 org.nep.nepsystem.NepsystemApplication
```
验证：curl http://localhost:8080/api/stats/overview 返回 code:200

### 前端（四端相同操作，各开一个终端）
```bash
cd C:\Users\LZ\Desktop\drenep\nepsystem-web && npm install && npm run dev    # 5173
cd C:\Users\LZ\Desktop\drenep\nepsystem-web-neps && npm install && npm run dev # 5174
cd C:\Users\LZ\Desktop\drenep\nepsystem-web-nepm && npm install && npm run dev # 5175
cd C:\Users\LZ\Desktop\drenep\nepsystem-web-nepg && npm install && npm run dev # 5176
```
npm install 可用镜像：`--registry=https://registry.npmmirror.com`
首次 dev 启动如遇黑屏：等待依赖预构建完成（10-30s）后 Ctrl+F5 刷新；仍黑执行 `npx vite optimize` 后重启。

## 5. 环境变量/配置

后端 `src/main/resources/application.properties`（不入库，从 application.example.properties 复制）：
```properties
server.port=8080
spring.datasource.url=jdbc:mysql://localhost:3306/nep?...
spring.datasource.username=root
spring.datasource.password=YOUR_MYSQL_PASSWORD
simulator.enabled=true        # 模拟数据开关
simulator.interval-ms=5000    # 上报间隔
```
前端代理（vite.config.js server.proxy）：/api 与 /ws → http://localhost:8080

## 6. 停止方式

- 后端：Ctrl+C（前台）；或结束 java 进程：`Get-Process java | Stop-Process`（按端口：netstat -ano | findstr 8080）
- 前端：终端 Ctrl+C 结束 vite
- 注意：后端 jar 运行中时 `mvn clean` 会因文件占用失败，先停进程

## 8. 生产部署要点

- `npm run build` 产物 dist/ 由 nginx 托管（SPA 需 try_files 回退 index.html；部署手册含示例 nginx.conf 与 docker-compose，仓库根未内置该两文件 [待补充]）
- /api 与 /ws 反代到 8080（WebSocket 需 Upgrade 头透传）
- 多端同域建议子路径或子域名区分，避免 cookie/localStorage 冲突（当前四端 key 已隔离：nep_token/nep_neps_*/nep_nepm_*/nep_nepg_*）
- MySQL 连接串请替换为环境变量注入，勿将真实密码入库
