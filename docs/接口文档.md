# 接口文档

> Base URL：`http://localhost:8080/api` · 统一返回：`{code, message, data}`（code=200 成功）
> 认证：登录后请求头携带 `Authorization: Bearer {token}`（当前课程设计实现为 UUID，未强制校验）

## 认证

### POST /auth/login 登录
```json
// 请求
{"adminCode":"admin","password":"123456"}
// 响应
{"code":200,"message":"登录成功","data":{"token":"...","adminId":1,"adminCode":"admin"}}
```

### POST /auth/logout 登出
无参数，返回 `{"code":200,...}`

## 设备 /api/devices

| 方法 | 路径 | 参数 | 说明 |
|---|---|---|---|
| GET | /page | page,size,keyword,type,status | 分页查询 |
| POST | / | body: Devices | 新增（device_code 唯一校验） |
| PUT | / | body: Devices | 修改 |
| DELETE | /{id} | - | 删除（有数据时拒绝） |
| GET | /online/count | - | 总数/在线数 |
| GET | /{id}/latest | - | 设备最新各指标值 |

## 监测数据 /api/data

| 方法 | 路径 | 参数 | 说明 |
|---|---|---|---|
| POST | /report | {deviceCode, items:[{sensorCode,value}], reportTime?} | 上报（写数据+更新设备+阈值告警，事务） |
| GET | /latest | deviceId, sensorCodes? | 最新数据 |
| GET | /history | deviceId?,sensorCode?,start?,end?,page,size | 历史分页（倒序） |
| GET | /trend | deviceId, sensorCode, start?,end?, interval=hour|day | 趋势聚合（平均/最大/最小） |
| GET | /export | deviceId?,sensorCode?,start?,end? | CSV 下载 |

### POST /data/report 示例
```json
{"deviceCode":"DEV-AIR-001","items":[{"sensorCode":"PM25","value":180}],"reportTime":"2026-08-25 10:00:00"}
```
→ PM25 超过报警上限 150 时自动生成 ALARM 告警并 WebSocket 广播。

## 告警 /api/alerts

| 方法 | 路径 | 参数 | 说明 |
|---|---|---|---|
| GET | /page | page,size,level?,status?,deviceId? | 分页 |
| PUT | /{id}/handle | handleUser? | 处理告警 |
| GET | /unhandled | - | 未处理数 + 最新 5 条 |
| GET | /stat | - | 近 7 天每日告警数（按级别） |

## 阈值 /api/thresholds

| POST | / | body | 新增 |
| PUT | / | body | 修改 |

## 统计 /api/stats

| 方法 | 路径 | 参数 | 说明 |
|---|---|---|---|
| GET | /overview | - | 设备总数/在线/今日上报/未处理告警 |
| GET | /quality | deviceId?,start?,end? | 环境质量评分（指标值/标准限值×100，>100 超标） |
| GET | /device-ranking | start?,end? | 上报量 Top10 |

## WebSocket

- 端点：`ws://localhost:8080/ws/notify`（前端经 Vite 代理 `/ws`）
- 消息类型：
  - `{"type":"data","deviceId":1,"deviceCode":"...","sensorCode":"PM25","value":165,"reportTime":"..."}`
  - `{"type":"alert","alertId":...,"level":"ALARM","sensorCode":"PM25","alertValue":165,"message":"..."}`

## 错误码约定

| code | 含义 |
|---|---|
| 200 | 成功 |
| 400 | 参数错误 |
| 401 | 未认证/账号密码错误 |
| 500 | 业务/系统异常 |
