# 数据库设计文档

> 库：`nep` · 字符集 utf8mb4 · 引擎 InnoDB · 初始化脚本：`nepsystem/src/main/resources/db/init.sql`

## ER 关系概览（ASCII）

```
regions ──< devices ──< monitor_data
                │            │
                │            └── sensors（指标字典，按 sensor_code 关联）
                │
                ├──< thresholds（device_id 可空 = 全局）
                └──< alerts

admins / users 为独立权限表
```

## 表结构

### 1. admins 管理员表
| 字段 | 类型 | 说明 |
|---|---|---|
| admin_id | INT PK 自增 | 管理员ID |
| admin_code | VARCHAR(50) UNIQUE | 账号 |
| password | VARCHAR(100) | 密码 |
| remarks | VARCHAR(255) | 备注 |
| create_time | DATETIME | 创建时间 |

### 2. users 用户表
| 字段 | 类型 | 说明 |
|---|---|---|
| id | INT PK 自增 | 用户ID |
| username | VARCHAR(50) UNIQUE | 用户名 |
| password | VARCHAR(100) | 密码 |
| nickname | VARCHAR(50) | 昵称 |
| role | VARCHAR(20) | ADMIN/USER |
| status | TINYINT | 1启用 0禁用 |
| create_time | DATETIME | 创建时间 |

### 3. regions 区域表
| 字段 | 类型 | 说明 |
|---|---|---|
| id | INT PK | 区域ID |
| name | VARCHAR(50) | 区域名称 |
| parent_id | INT | 父区域（0=顶级） |
| description | VARCHAR(255) | 描述 |

### 4. devices 监测设备表
| 字段 | 类型 | 说明 |
|---|---|---|
| id | INT PK 自增 | 设备ID |
| device_code | VARCHAR(50) UNIQUE | 设备编号（上报用） |
| device_name | VARCHAR(100) | 设备名称 |
| type | VARCHAR(20) | AIR/WATER/NOISE |
| region_id | INT | 所属区域 |
| location | VARCHAR(255) | 安装位置 |
| status | TINYINT | 0离线 1在线 2停用 |
| last_report_time | DATETIME | 最近上报 |
| create_time | DATETIME | 创建时间 |

### 5. sensors 指标字典表
| 字段 | 类型 | 说明 |
|---|---|---|
| id | INT PK | 指标ID |
| sensor_code | VARCHAR(30) UNIQUE | TEMP/HUMI/PM25/CO2/PH/TURBIDITY/DO/NOISE |
| sensor_name | VARCHAR(50) | 名称 |
| unit | VARCHAR(20) | 单位 |
| device_type | VARCHAR(20) | 适用设备（NULL=通用） |
| min_range / max_range | DECIMAL(10,2) | 量程 |
| standard_max | DECIMAL(10,2) | 标准限值（超标判定） |

### 6. monitor_data 监测数据表（核心）
| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT PK 自增 | 数据ID |
| device_id | INT | 设备ID（索引 idx_device_time） |
| sensor_code | VARCHAR(30) | 指标编码 |
| value | DECIMAL(10,2) | 数值 |
| report_time | DATETIME | 上报时间 |
| create_time | DATETIME | 入库时间 |

### 7. thresholds 告警阈值表
| 字段 | 类型 | 说明 |
|---|---|---|
| id | INT PK | 阈值ID |
| device_id | INT NULL | 设备ID（NULL=全局默认） |
| sensor_code | VARCHAR(30) | 指标编码 |
| warn_min / warn_max | DECIMAL(10,2) | 预警区间 |
| alarm_min / alarm_max | DECIMAL(10,2) | 报警区间 |
| enabled | TINYINT | 启用开关 |
| update_time | DATETIME | 更新时间 |

### 8. alerts 告警记录表（核心）
| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT PK 自增 | 告警ID |
| device_id | INT | 设备ID |
| sensor_code | VARCHAR(30) | 指标编码 |
| level | VARCHAR(10) | WARN/ALARM |
| alert_value | DECIMAL(10,2) | 触发值 |
| message | VARCHAR(255) | 描述 |
| status | TINYINT | 0未处理 1已处理 |
| handle_user / handle_time | VARCHAR(50)/DATETIME | 处理人/时间 |
| create_time | DATETIME | 告警时间 |

## 核心设计决策

1. **monitor_data / alerts 用 BIGINT 自增主键**，并建立 (device_id, report_time) 复合索引支撑时序查询。
2. **阈值两级告警**：预警 WARN（提醒）与报警 ALARM（紧急），设备级阈值优先于全局默认。
3. **防重复告警**：同一设备同一指标同一级别 30 分钟内不重复（业务层判断）。
4. **指标字典驱动**：所有上报指标编码必须在 sensors 表登记，前端按字典渲染单位与标准限值。
