# 部署手册

## 方式一：Windows 本机部署（推荐）

### 1. 数据库初始化
```bash
mysql -uroot -p < nepsystem/src/main/resources/db/init.sql
mysql -uroot -p < nepsystem/src/main/resources/db/generate_demo_data.sql   # 可选演示数据
```

### 2. 后端
```bash
cd nepsystem
mvn clean package -DskipTests
java -jar target/nepsystem-0.2.0.jar
# 后台运行（Windows）：
# start /b java -jar target/nepsystem-0.2.0.jar
# 验证：http://localhost:8080/api/stats/overview 返回 code:200
```

### 3. 前端（开发模式）
```bash
cd nepsystem-web
npm install --registry=https://registry.npmmirror.com
npm run dev        # http://localhost:5173（/api 与 /ws 自动代理到 8080）
```

### 4. 前端（生产模式，Nginx 托管）
```bash
cd nepsystem-web
npm run build      # 产物在 dist/
```

nginx.conf 关键配置：
```nginx
server {
    listen 80;
    server_name localhost;
    root C:/Users/LZ/Desktop/drenepsystem/nepsystem-web/dist;

    location / {
        try_files $uri $uri/ /index.html;   # SPA 路由
    }
    # 后端 API 反代
    location /api/ {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
    }
    # WebSocket 反代
    location /ws/ {
        proxy_pass http://127.0.0.1:8080;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
    }
}
```

## 方式二：Docker Compose（可选）

```yaml
# docker-compose.yml（需将 mysql 密码与账号改为实际值）
services:
  mysql:
    image: mysql:8.0
    environment:
      MYSQL_ROOT_PASSWORD: 124102
      MYSQL_DATABASE: nep
    ports: ["3306:3306"]
    volumes:
      - ./nepsystem/src/main/resources/db/init.sql:/docker-entrypoint-initdb.d/init.sql:ro

  backend:
    build: ./nepsystem
    depends_on: [mysql]
    ports: ["8080:8080"]
    environment:
      SPRING_DATASOURCE_URL: jdbc:mysql://mysql:3306/nep?useSSL=false&serverTimezone=Asia/Shanghai
      SPRING_DATASOURCE_PASSWORD: 124102

  frontend:
    image: nginx:alpine
    depends_on: [backend]
    ports: ["80:80"]
    volumes:
      - ./nginx.conf:/etc/nginx/conf.d/default.conf:ro
      - ./nepsystem-web/dist:/usr/share/nginx/html:ro
```

## 常见问题

| 问题 | 处理 |
|---|---|
| 启动报数据库连接失败 | 确认 MySQL 运行、application.properties 密码正确 |
| mvn package 无法删除旧 jar | 先停掉运行中的 java 进程 |
| 前端 5173 打不开 | 确认 npm install 成功、dev server 日志无报错 |
| 大屏无数据 | 确认模拟器开启（application.properties: simulator.enabled=true），或手动 POST /api/data/report |
| npm install 失败 | 使用镜像：--registry=https://registry.npmmirror.com |
